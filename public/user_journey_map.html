Pain Point——접수와 확정의 차이를 명확히 이해해야 함처리 시점을 알기 어려움사용자가 직접 결과를 확인해야 함확정 시점을 알 수 없어 반복 확인해야 하며 일정 조율이 어려움

핵심 Pain Point

예약 확정 시점과 결과를 예측할 수 없고, 예약이 불가능할 경우 다시 일정을 탐색·신청한 뒤 동일한 확정 대기를 반복해야 해 불안과 피로가 커진다.

개선 목표

사용자가 직접 반복 확인하지 않아도 예약 상태를 명확히 알 수 있게 하고, 재선택이 필요한 경우 다음 행동으로 바로 이어질 수 있도록 한다.
